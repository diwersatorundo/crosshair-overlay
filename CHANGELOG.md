# Changelog

## 0.2.0

- Закрытие окна теперь сворачивает приложение в системный трей; выход — через меню трея.
- Новый монохромный интерфейс: фон `#0a0a0a`, элементы `#171717`, единое скругление 5 px.
- Увеличен размер текста и элементов управления.
- Убран блок пресетов, share code перенесён в начало настроек.
- Исправлено дублирование настройки зазора.
- В README и интерфейсе добавлено упоминание, что проект вайб-код.

## 0.1.0

- Первый публичный релиз.
- Внешний статичный Direct2D-оверлей для Windows.
- 10 стилей прицела, пресеты, цвета, геометрия и обводка.
- Импорт и экспорт CS2/legacy share code.
- Горячая клавиша `Ctrl+Alt+X`.
- Автозапуск при входе в Windows.
- Установщик NSIS с выбором папки, ярлыком в меню «Пуск», ярлыком на рабочем столе и деинсталлятором.
- Портативная сборка и CI/release workflow для GitHub.
